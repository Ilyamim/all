# Startup Club Platform

This repository houses the code for the Startup Club Platform, a web application that enables students, mentors, and administrators to collaborate on projects and track volunteer hours.

## Frontend

The `frontend` directory contains a React application bootstrapped with Vite and configured with Tailwind CSS.

### Getting Started

1. Navigate to the frontend folder:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

### Building

To create a production build:
```bash
npm run build
```
