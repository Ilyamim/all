# Stretching Studio Website

This repository contains a simple website for a stretching studio. The main files are located in the `stretching-studio` directory:

- `index.html` – the homepage with sections for about, classes, and contact
- `style.css` – basic styling for the page
- `script.js` – JavaScript used by the contact form

To view the website, open `stretching-studio/index.html` in your browser.
